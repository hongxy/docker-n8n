# n8n Docker Setup

This repository provides a **Docker Compose–based setup for n8n**, allowing you to quickly start a self-hosted automation server with persistent data.

---

## Prerequisites

- Docker Desktop (Windows / macOS / Linux)
- Docker Compose (v2)
- (Windows users) WSL2 enabled and integrated with Docker Desktop

Verify:
```bash
docker --version
docker compose version
\```


## Quick Start

### Clone the repository
```bash
git clone <your-repo-url>
cd <repo-folder>
docker compose up -d
